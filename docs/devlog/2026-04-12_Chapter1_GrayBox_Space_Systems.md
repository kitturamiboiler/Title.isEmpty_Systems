## 5. 우산 오프닝 연출 — 픽셀·물리 감각 (2026-04-12 코드 반영)

| 항목 | 내용 |

| **PPU / 픽셀** | 우산 **hold 스프라이트 PPU 16** → 1픽셀 = **1/16 (= 0.0625)**. **펼침(open / pull)만 PPU 8** → 1픽셀 = **1/8 (= 0.125)**. 코드 상수 `OnePixelWorldUnitUmbrellaHoldPpu16`, `OnePixelWorldUnitUmbrellaPullPpu8`. Pixel Perfect에서는 1픽셀 미만 오프셋 지양. |

## 7. 레벨 구간 기획서(로드맵)에 대한 짧은 코멘트

보내주신 **[연출 → 이동 → 분식집 → 가을 골목 → 전투 튜토 → 귀가 컷]** 타임라인 기준으로 보면, 이 튜토리얼은 조작 익히기만이 아니라 **현과 연서의 정서적 유대**를 쌓는 빌드업 구간이다. **「반만요」·9년 전 플래시백**이 앞에서 쫀득할수록, 후반 **상실감** 설계와도 맞물린다.

- **분식집(Rest)**: 이동·점프 텐션 뒤 **조작 없이** 대화와 빗소리에 몰입시키는 페이싱은 내러티브적으로 매우 유리하다. 다만 그걸 담당할 **정지 연출 시스템**은 아직 비어 있으니 다음 스프린트의 1순위로 두는 것이 좋다.
- **전투 튜토(귀갓길)**: 단도·블링크를 불량배와 연결하고, **한 방에 쓰러지는 허수아비**로 초반 자신감을 주는 구성은 초학습 곡선에 잘 맞는다.
