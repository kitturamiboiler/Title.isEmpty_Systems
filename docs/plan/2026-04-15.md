## 4. 코드 가이드라인 (Copy-ready Deliverables)

### Cinemachine 줌인 제어 (코루틴 힌트)

```csharp
public IEnumerator ZoomInSequence(float targetSize, float duration)
{
    var framingTransposer = virtualCamera.GetCinemachineComponent<CinemachineFramingTransposer>();
    float startSize = virtualCamera.m_Lens.OrthographicSize;
    float elapsed = 0f;
    while (elapsed < duration)
    {
        elapsed += Time.deltaTime;
        virtualCamera.m_Lens.OrthographicSize = Mathf.Lerp(startSize, targetSize, elapsed / duration);
        yield return null;
    }
}
```

> 실제 프로젝트에서는 `CinemachineFramingTransposer` 사용 여부·렌즈만 조정할지는 씬 프리셋에 맞게 조정.
